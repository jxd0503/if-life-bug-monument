# if 人生 · BUG 纪念碑

> 献给每一个还在 Build 的人。

一座开发者公墓，一段可重玩的人生叙事交互页。你将经历 9 个「人生主节点」与若干隐藏节点，每个节点做一次选择；每个选择都有「现实结局」和「平行结局」两种叙事，并实时影响四维属性。全部走完后按「属性 + 选择 + 隐藏节点」判定九种终局结局之一，生成专属个人纪念碑，并支持导出分享卡片 PNG。

**在线体验：** https://jxd0503.github.io/if-life-bug-monument/

---

## 玩法流程

```
开场屏 → 9 个主节点（含随机事件）→ 隐藏节点（满足条件时）→ 终局判定 → 个人纪念碑 → 分享卡片导出
```

- **开场屏**：月光下的开发者公墓 + 空碑「我的人生」。若已有存档，显示「这里立着一座属于你的碑」，可直达纪念碑或重新开始。
- **节点屏**：场景叙事（打字机 / 淡入）→ 选项卡片（标注属性变化预览）。
- **结局屏**：先「现实结局」再「平行结局」，最后墓碑刻字动画（打字机）。
- **终局屏**：节点 9 选择后，按判定给出九种结局之一的完整动画与文案。
- **纪念碑生成屏**：专属碑文 + 标签 + 属性 + 统计 + 「生成分享卡片」「重新选择」按钮。
- **图鉴页 / 成就页**：可从纪念碑屏进入查看。

## 机制

### 属性系统

技术 / 胆识 / 财富 / 心态 四维，初始各 5，范围 0–10。页面右上角常驻显示属性面板，变化时数值滚动动画。

### 选项风格与隐藏节点

- 每个选项标注 `[冒险]` / `[稳健]` / `[中性]`
- 连续 3 次 `[冒险]` → 节点 8 后触发隐藏节点 **H1｜红蓝药丸**
- 连续 3 次 `[稳健]` → 触发 **H2｜隐居大佬的邀请**
- 财富 ≥ 7 且 胆识 ≥ 7 → 触发 **H3｜风口**

### 随机事件

节点 3 后和节点 6 后各随机插入 1 个事件（从事件池中随机，每次重玩可能不同）。

### 终局判定

- 节点 9 选 **B** → 直接 **E9｜未完待续**
- 节点 9 选 **A** → 按优先级表判定：`E7 → E6 → E1 → E8 → E2 → E4 → E5 → E3`

### 九种结局

| 编号 | 结局名 | 判定条件 |
| --- | --- | --- |
| E1 | 传奇·开源大神 | 技术 ≥ 8 且 胆识 ≥ 7 |
| E2 | 人生赢家 | 财富 ≥ 8 且 心态 ≥ 7 |
| E3 | 平凡而幸福 | 以上均不满足（兜底） |
| E4 | 燃尽 | 心态 ≤ 3 且 胆识 ≥ 6 |
| E5 | 逃离·咖啡店 | 心态 ≤ 4 且 财富 ≥ 4 |
| E6 | 隐居·守墓人 | 隐藏节点 H2 选了「接受邀请」 |
| E7 | 觉醒 | 隐藏节点 H1 选了「红药丸」 |
| E8 | 1024 高光 | 节点 9 选 A 且 技术 ≥ 8 |
| E9 | 未完待续 | 节点 9 选了 B（无论属性） |

### 成就系统

15 个成就按条件实时解锁，成就页展示。包含「甲方爸爸」「MVP 之王」「躺平大师」「大厂螺丝钉」「创业冲锋者」「自由猎手」「回滚大师」「夜猫子」「All in 勇者」「稳如老狗」「冒险狂徒」「真相探秘者」「1024 见证者」「墓碑收藏家」「多面人生」。

### 图鉴收集

每个节点每个选项对应一块墓碑，选择后入图鉴。图鉴页显示「已收集 X / 共 27 块」，可查看全部碑文。另有彩蛋碑「404 之魂」——他不是不见了，他只是没找到。

### 个人纪念碑

按「短句映射表」拼接专属碑文，显示结局名、玩家标签（传奇 Builder / 人生赢家 Builder / 觉醒 Builder / 守墓 Builder / 需要 sleep 的 Builder / 在路上的 Builder）、属性面板、成就 / 图鉴统计。

### 分享卡片

用 Canvas 绘制并导出 PNG，尺寸与文案规格见 `data.js` 的 `shareCard`。

## 技术说明

纯静态多文件项目，**无构建步骤、无后端**。双击 `index.html` 即可运行，不依赖任何构建工具。

```
If Life A Bug Monument/
├── index.html      # 页面骨架，用相对路径引入下面三个文件
├── style.css       # 全部视觉样式与动效
├── data.js         # 全部剧情与机制数据（全局对象 window.STORY_DATA）
└── script.js       # 全部页面逻辑
```

- `data.js` 只放数据（nodes / choices / endings / epitaphs / events / achievements / collection / 短句映射表），不含页面逻辑
- `script.js` 负责流程控制、属性系统、结局判定、localStorage、Canvas 导出、彩蛋
- 数据与逻辑分离：**改文案只需改 `data.js`，不触碰 `script.js`**
- 字体使用本地等宽字体栈（Consolas / Courier New），页面无任何外部网络请求
- 存档基于 localStorage，「重新选择」可清空重玩；多次重玩可达成不同结局（结局达成记录保留）

## 视觉风格

配色深蓝夜空 `#0b1026`、月光白 `#e8f4ff`、终端绿 `#7ee787`、碑文灰 `#8b93a7`；背景为悬浮淡绿代码雨（低透明度 canvas）与右上角圆月；墓碑由 CSS 绘制，hover 浮现碑文。气质安静、肃穆，但带程序员式浪漫。
